# Notes 1

## What is Markdown?
Markdown is a simple markup language used to format text using symbols. It can be used to create headings, bold text, lists, links, images, and more.

## What is Git?
Git is a version control system that tracks changes to files and code. It allows developers to save different versions of their work and go back to previous versions if needed.

## What is GitHub?
GitHub is an online platform that uses Git to store, manage, and share code and other projects. It also allows people to collaborate on projects.

## What is Slack?
Slack is a communication and collaboration platform used by teams to communicate through channels, direct messages, file sharing, and other tools.
